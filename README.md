# FormularioHTML-css
Ejercicio de introducción a Git

1. Crear un usuario en GitHub
2. Instalar Git en tu computadora
3. Crear un nuevo repositorio e incluir la entrega del formulario
4. Sincronizar tu copia local con el repositorio remoto en GitHub
5. Realizar pequeños cambios en el formulario y hacer los commits correspondientes
6. Compartir el enlace a tu repositorio en este foro, junto con las dificultades que hayas tenido durante la actividad
****Pueden agregar un Readme, y si el trabajo está en una rama particular mencionar cual es.
